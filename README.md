# پایگاه خبری صدای کرج

این سایت آرشیو محلی پست‌های عمومی حساب `@seday.ekaraj` را نمایش می‌دهد. تصاویر بندانگشتی و کپشن‌ها در مخزن ذخیره شده‌اند.

## همگام‌سازی خودکار

فایل `.github/workflows/sync-instagram.yml` هر روز داده‌های جدید را از Instagram Graph API دریافت می‌کند. در تنظیمات مخزن، Secrets زیر را اضافه کنید: `INSTAGRAM_ACCESS_TOKEN` و `INSTAGRAM_USER_ID`. برای حفظ رسانه‌ها، workflow تصویر بندانگشتی پست‌های تازه را در `assets/` ذخیره و `posts.json` را به‌روزرسانی می‌کند.
